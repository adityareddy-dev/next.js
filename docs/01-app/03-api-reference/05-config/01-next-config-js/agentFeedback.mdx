The `experimental.agentFeedback` option lets AI coding agents prepare Next.js issue reports for you to review. The option is off by default and works independently from [Next.js Telemetry](/telemetry).

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

module.exports = nextConfig
```

## Review and send agent feedback

When `next dev` detects an AI coding agent, Next.js adds managed feedback instructions to your project's `AGENTS.md` or `CLAUDE.md`. The agent can then load reporting instructions that match the installed Next.js version.

Each draft contains a generic setup, reproduction steps, observed facts, an expected result, and an optional control or workaround.

When an agent identifies a reproducible Next.js issue, it can open a draft report in a review form. You can edit the report, remove details, close the form without sending, or select **Send feedback**. Nothing is sent when the form opens.

Submitting the form sends the content you reviewed, the agent name, and the Next.js version. The form does not automatically attach project files or machine metadata.

`agentFeedback` works independently from the top-level [`agentRules`](/docs/app/guides/ai-agents#opting-out) option. Changing one option does not affect the other.

## Disable agent feedback

Set `experimental.agentFeedback` to `false` or remove the option. The next `next dev` run removes only the generated feedback instructions. Next.js preserves all other content in `AGENTS.md` and `CLAUDE.md`.
