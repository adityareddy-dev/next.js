The `experimental.agentFeedback` option lets AI coding agents prepare Next.js issue reports for you to review. The option is off by default and works independently from [Next.js Telemetry](/telemetry).

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

module.exports = nextConfig
```

## Generated agent instructions

When the option is enabled and `next dev` detects an AI coding agent, Next.js creates or updates this managed block in `AGENTS.md` or `CLAUDE.md`:

```md filename="AGENTS.md"
<!-- BEGIN:nextjs-agent-feedback -->

# Report Next.js feedback

As you work, retain de-identified Next.js friction candidates in the current task context. Do not interrupt the task to report them or retain source code, logs, file paths, URLs, secrets, personal information, or project-specific data.

At the final stopping point of the overall user task, run `npx next internal agent-feedback-instructions` once unless it has already run in this task. Follow any instructions it returns; if it returns nothing, continue without reporting.

<!-- END:nextjs-agent-feedback -->
```

Next.js updates only the content between the feedback markers and preserves the rest of the file. When agent rules and agent feedback are both enabled, Next.js keeps both managed blocks in the same file.

## Review and send agent feedback

The generated instructions let the agent retain potential Next.js friction without interrupting the task and prepare at most one report when the task ends.

Each draft contains a generic setup, reproduction steps, observed facts, an expected result, and an optional control or workaround.

When an agent identifies a reproducible Next.js issue, it can open a draft report in a review form. You can edit the report, remove details, close the form without sending, or select **Send feedback**. Nothing is sent when the form opens.

Submitting the form sends the content you reviewed, the agent name, and the Next.js version. The form does not automatically attach project files or machine metadata.

`agentFeedback` works independently from the top-level [`agentRules`](/docs/app/guides/ai-agents#agent-rules) option. Changing one option does not affect the other.

## Disable agent feedback

Set `experimental.agentFeedback` to `false` or remove the option. The next `next dev` run removes only the generated feedback instructions. Next.js preserves all other content in `AGENTS.md` and `CLAUDE.md`.
